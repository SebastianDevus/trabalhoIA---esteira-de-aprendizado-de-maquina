# Trabalho de IA - Esteira de aprendizado de máquina
Este projeto consiste no desenvolvimento de uma esteira de aprendizado de máquina em python, começando da importação e preparação dos dados, até a realização de previsões com o modelo treinado

A base de dados escolhida foi [Estimation of Obesity Levels Based On Eating Habits and Physical Condition](https://archive.ics.uci.edu/dataset/544/estimation+of+obesity+levels+based+on+eating+habits+and+physical+condition)

O modelo realiza uma tarefa de **classificação**, utilizando o algoritmo Random Forest

O projeto foi criado e executado no Google Colab, especificamente.
